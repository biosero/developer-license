# Biosero Developer License Agreement

This repository holds the Biosero Developer License Agreement
(short ID `LicenseRef-Biosero-Developer`). It is the license for Biosero's
publicly published developer packages on [nuget.org](https://www.nuget.org/),
such as the Green Button Go and Device Manager packages.

The full text is in [LICENSE](LICENSE).

## Which copy applies

Each package includes a copy of the license. The copy included in a package
version is the one that governs that version. The copy in this repository is
provided for reference only.

## License versions

Each released version of the license is tagged `vMAJOR.MINOR`, starting with
`v1.0`. A tag is created only after the version is approved, and a tag is never
moved once it is created. The `main` branch may contain unreleased changes.

Biosero product builds fetch the license from a pinned tag, never from `main`:

```
https://raw.githubusercontent.com/biosero/developer-license/<tag>/LICENSE
```
